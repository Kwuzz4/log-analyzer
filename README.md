# log-analyzer
Скрипт для анализа логов и поиска атак

Я сделал этот проект, когда учился писать на Python. Мне было интересно, как работают системные администраторы и системы безопасности, поэтому я решил написать простой скрипт. Он анализирует серверные логи из файла log.txt и ищет там подозрительные записи.

Вот как он работает:
Скрипт читает файл с логами.
Он ищет строки, в которых есть слова вроде "ERROR" или "Failed".
Из этих строк он вытаскивает IP-адреса.
Затем он считает, сколько раз каждый IP-адрес ошибался при попытке входа.
Если какой-то IP-адрес ошибся три раза или больше, скрипт выводит сообщение в консоль: "С адреса ... идет атака". Это похоже на попытку угадать пароль методом перебора.

Чтобы его запустить:
Скачайте файлы.
Поместите в одну папку файл log_analyzer.py (или как вы назвали скрипт) и файл log.txt.

Запустите программу.
